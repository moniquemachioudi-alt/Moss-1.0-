# Moss-1.0-
Moss is a built-in tool that optimizes plant survival using different sensors, including light, moisture, and temperature. The Moss app features a user-friendly interface that delivers real-time data and guidance to support optimal plant survival. 

Code Stack and Architecture 

1. Firmware - C++(Arduino)
2. Data Storage - PostgreSQL 
3. Backend - Python/FastAPI for Data Processing and AI Logic
4. Frontend - React for Live Update Dashboard without Page Refreshers
5. Communication - MQTT or WebSockets for User Pop-Ups notifications
